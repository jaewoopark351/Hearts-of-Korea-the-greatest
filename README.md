# Hearts of Korea: The Greatest

**Hearts of Korea: The Greatest**는 `하츠 오브 코리아 / Hearts of Korea`를 계승하는 별도 후속 프로젝트이자, 한국을 의도적으로 강하게 만드는 Hearts of Iron IV 한국 강화 모드입니다.

> 현재 상태 (2026-11-14): 최신 원본 `0c19f58`의 새 표식 두 개와 세 지휘관 해금 조건을 **우리 기존 두 파일에 반영**했습니다. 기존 버프의 바이트 보존·구문 검사 54 PASS / 0 FAIL, 독립 정적 검사 65 PASS / 0 FAIL입니다. [반영·검증 기록](docs/UPSTREAM_UPDATE_PLAN.md#후속-구현-결과)을 참조하세요. 게임 실행·기존 저장·RT56은 미검증이며, 전체 원본을 이관한 독립 후속 빌드는 아닙니다.

> 이전 구현·검증 (2026-11-06): 작은 `국뽕팩` 애드온 구조를 유지하면서 당시 원본의 인물·아이디어·국가 history를 병합하고 descriptor 연결을 갱신했습니다. 기존 버프와 전용 파일의 정적 보존 대조는 1,937 PASS / 0 FAIL입니다. HOI4 1.19.4.2·DLC 36개에서 새 한국 게임과 정치력 +1500·연구 슬롯 6개·분야별 혁신 30, 삼성전자 채용 후 연구 속도 +50005% 표시를 확인했습니다. 완전 재시작 후 새 테스트 저장을 불러와 진행·재저장했고 선택 필드 136 PASS / 0 FAIL을 확인했습니다. 게임·런처 종료, 설정·기존 저장 복구와 Steam 녹색 플레이 표시 복귀도 확인했습니다. [구현·검증 기록](docs/incidents/2026-11-06-upstream-overlay-update.md)을 참조하세요. 이 결과는 11월 14일 원본 조합의 검증 결과가 아닙니다.

## 프로젝트 목표

- 원본 코드와 콘텐츠의 출처, 저작자, 안정적인 ID, 디자인 역사를 보존합니다.
- 목표 HOI4 버전에서 동작하는 추적 가능한 복원 기준선을 먼저 구축합니다.
- 복원 작업과 분리하여 한국의 국가 운영·경제·군사·인물·콘텐츠를 의도적으로 강화합니다.
- 기존 Workshop 항목을 덮어쓰지 않고 새로운 후속 항목으로 공개합니다.

## 현재 우선 작업: 기존 국뽕팩의 원본 업데이트 대응

[원본 업데이트 반영 계획](docs/UPSTREAM_UPDATE_PLAN.md)에 따라 최신 원본을 기반 모드로
사용하고, 우리 파일이 가리는 정의만 최신 내용과 병합하는 방식을 우선합니다.
원본 전체 복사는 이번 대응의 선행 조건이 아닙니다. 기존 버프의 수치·조건·적용 범위를
유지하며, 상시 버프를 새 선택형 프리셋으로 옮기거나 구조를 분해하지 않습니다.

11월 14일에는 문서화 후 구현 요청에 따라 기존 두 파일의 누락을 반영했습니다.
기존 버프와 구 국뽕 저장 예외 조건의 소스 보존을 확인했으며, 실제 새 게임·기존 저장·
일반 1.19판·RT56판의 별도 실행 검증은 남아 있습니다.
`common/ideas/korea.txt`는 이전 반영 원본 이후 변경이 없어 이번 재병합 근거가 없습니다.

11월 6일에는 문서화 이후 구현 요청에 따라 코드 병합을 진행했습니다. 사용자가 새 플레이세트 생성·
수정과 테스트를 명시적으로 허가하여 설정 백업 후 실행했습니다. 로드 경로·DLC와 실제 버프 효과의
확인 범위는 [구현 기록](docs/incidents/2026-11-06-upstream-overlay-update.md)을 따릅니다.
새 테스트 저장의 재로드와 설정·기존 저장 복구는 확인했습니다. 모든 버프·MIO 효과나
변경 전 저장의 호환성을 입증한 것은 아닙니다. Steam의 플레이 표시 복귀와 재시작 후
설정·기존 저장 보존도 다시 확인했습니다.
독립 후속작을 위한 전체 이관과 새로운 최강 프리셋 개발은 별도 계획으로 남깁니다.

## 디자인 방향

- 경제·산업 성장과 건설 역량을 강화합니다.
- 육군·해군·공군, 지휘관과 조언가가 강한 한국을 만듭니다.
- 국민정신, 중점, 이벤트, 결정에서 한국 고유의 성장 경로를 확장합니다.
- 강력한 보너스는 의도적으로 설계하되 수치의 단위와 상한, AI 반응, DLC 조건을 검증합니다.
- 파서 오류, 누락 참조, 무한 이벤트, 크래시, 전역 시스템 오염은 강화 요소로 취급하지 않습니다.
- 지도·주·OOB·세이브 호환성 변경은 별도의 고위험 작업으로 다룹니다.

- 원본의 바이너리 자산, 경로 대소문자, ID, 현지화 키와 UTF-8 BOM을 보존합니다.
