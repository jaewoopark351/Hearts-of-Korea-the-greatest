작성일: 2026-11-06 (Asia/Seoul)  
상태: **코드 반영·정적 대조 1,937 PASS / 0 FAIL. 새 게임·일부 버프와 완전 재시작 후 신규 저장 재로드·진행·재저장 확인. 게임·런처 종료와 설정·기존 저장 복구, Steam 플레이 표시 복귀 확인. 실제 범위는 [구현 기록](incidents/2026-11-06-upstream-overlay-update.md) 참조.**

## 1. 이번 작업의 방향과 경계

현재 국뽕팩의 작은 애드온 구조를 유지한다. 최신 원본을 기반 모드로 함께 로드하고,
우리 파일이 덮어쓰는 정의만 최신 내용에 맞춘 뒤 기존 버프를 보존하는 방식이다.
원본 전체를 우리 폴더로 복사하는 작업은 이번 업데이트 대응의 선행 조건이 아니다.
현재 추적 중인 게임 로직·정의 파일은 8개, 현지화는 6개다. descriptor·이미지·프로젝트
문서는 이 수량에서 제외하며, 파일 수를 늘리는 재구성보다 기존 구조를 우선한다.

최초 요청은 **이 방법의 문서화만**이었고, 이후 사용자가 구현을 요청했다.
문서화만 했던 단계의 제한을 이후 구현·테스트 단계의 상태로 사용하지 않는다. 사용자가
새 플레이세트 생성·수정과 테스트를 후속 허가하여 설정 백업 후 실행했다. HOI4 1.19.4.2·
DLC 36개에서 새 한국 게임·정치력 +1500·연구 슬롯 6개·분야별 혁신 30과 삼성전자 채용 후
연구 속도 +50005% 표시를 확인했다. 아래는 계획과 보존 계약이며 실제 코드 변경·정적 검사·
실행 관측과 미검증 범위는 구현 기록으로 구분한다. 이후 완전 재시작 후 새 테스트 저장을
불러와 1936.01.10.10까지 진행·재저장했고 선택 필드 136 PASS / 0 FAIL을 확인했다.
게임·런처 종료와 원래 설정·기존 저장 복구, Steam 플레이 표시 복귀도 확인했다.
Steam 재시작 후 설정·기존 저장·플레이세트 보존을 재확인했다. 엔진의 저장 이름 전환
실패는 미해결이다. 커밋·푸시·배포는 하지 않는다.

독립 후속작을 만드는 [전체 소스 이관](SOURCE_MIGRATION_PLAN.md)과
[새 최강 프리셋 개발](GREATEST_MODE_DESIGN.md)은 별도 작업으로 남긴다.
기존 버프를 여러 모듈이나 새 ID로 분해하거나, 상시 버프를 새 선택형 옵션으로 옮기는
재설계는 이번 업데이트 반영에 포함하지 않는다.

## 3. 반영 방식

### 원본에 맡기는 부분

우리 파일이 가리지 않는 중점·결정·이벤트·AI·이미지·현지화·지도 등은 최신 기반 모드에서
사용한다. 최신 원본에는 한국 중점 474개, 재벌·시민사회 내정, MIO 전문화, 연구시설·
과학자 성장, 교리 수리, 민간 핵 연구 등의 변경이 있다. 이를 우리 폴더에 다시 복제하지 않는다.
현재 기준은 원본의 [기능 연동 명세](../../hearts_of_korea/docs/HOK_KOREAN_FEATURE_INTEGRATION_SPEC.md)와
위 민간 핵 연구 명세를 참조한다.

이는 실행 구성에 대한 계획이며, 후속 테스트의 실제 3모드 로드와 관측 범위는 구현 기록에
분리했다. 모든 파일의 발견·평가를 입증한 것은 아니므로 물리적 모드 경로, 의존성,
파일·정의 ID와 `replace_path`의 검토 범위를 구분한다.

### 핵심 병합 대상 세 파일

| 우리 파일 | 최신 원본에서 유지할 내용 | 우리 쪽에서 보존할 내용 |
|---|---|---|
| `common/characters/KOR.txt` | 최신 인물·역할·조건·초상화·특성·참조 ID | 지휘관 능력치와 국뽕 특성 변경분 |
| `common/ideas/korea.txt` | 최신 국민정신·제조사 정의와 추가·수정된 효과 | 우리 고유 국민정신 보너스, 제조사 16곳의 국뽕 특성 연결 |
| `history/countries/KOR - Korea.txt` | 최신 시작 설정, 정치·OOB·교리·인물 초기화와 지도 참조 | 하루 뒤 `HoK_Greatest.0` 호출과 그 보너스가 적용되는 흐름 |

각 파일은 최신 원본 정의를 기준으로 우리 고유 변경분을 항목별로 반영한다.
우리 구형 파일 전체를 유지하거나 최신 원본 파일로 무조건 덮어쓰지 않는다.
인물·특성 등의 ID는 대소문자까지 대조하고, 의도적인 참조 이동이 필요하면 대응표를 남긴다.
수도·OOB·인물 ID 같은 구조 차이는 능력치 버프와 구분한다. 지도 자체 수정은 이 계획에 없다.

구현 전에 확인한 충돌 예시는 다음과 같다. 아래 우리 값은 병합 전 값이다.

- 최신 원본의 `KOR_vision_1950`은 조선소 생산 `0.3`이고 우리 파일은 옛 `0.2`다.
  우리 파일을 그대로 덮어 최신 강화가 되돌아가지 않게 한다.
- 최신 원본의 `KOR_stop_moderate_diplomacy_idea`에는 의용군 긴장도 `-0.50`과
  추가 5사단 효과가 있다. 우리의 `-0.25`로 되돌리거나 두 값을 임의 합산하지 않는다.
- 우리 `KOR_homeland_defence_special_act_ideas`의 핵심 영토 공격·방어 각 `0.05`와
  제조사 국뽕 특성 연결은 최신 원본만 복사해서 잃지 않게 한다.
- 최신 원본의 유일한 특성 `financial_expert`와 현행 교리 초기화 `set_grand_doctrine`
  3종을 우리 파일의 오래된 상속 내용으로 되돌리지 않는다.

근거 파일은 읽기 전용 원본의 `common/ideas/korea.txt`, `common/characters/KOR.txt`,
`history/countries/KOR - Korea.txt` 및 우리 저장소의 같은 상대 경로다.

## 4. 버프 보존 기준

- 기존 버프의 효과·수치·조건을 임의로 줄이거나 삭제하지 않는다. 상시 효과와 옵션형 효과의 기존 구분을 유지한다.
- 새로운 모듈·ID·선택 조건을 추가하는 리팩터링 없이 기존의 간결한 구조를 우선한다.
- 비용·위험·기간 감소는 부호와 단위가 다르므로 숫자가 큰 값을 자동 선택하지 않는다. 같은 효과를 무조건 더하지도 않는다.
- 최신 원본에 같은 항목의 추가 강화가 있으면 그 변경과 기존 버프의 이점을 함께 검토하고, 최종 값·근거를 기록한다.
- 사용되지 않는 옛 키는 조용히 삭제하지 않는다. 대상 버전의 유효한 방식으로 같은 효과를 낼 수 있는지 확인하고, 의미가 달라지면 차이를 먼저 기록한다.
- 제조사 특성이나 MIO 보너스는 정의의 존재뿐 아니라 해당 DLC·선택 조건에서 실제 적용되는 경로를 확인한다.
- 기존의 전역 효과를 한국 한정으로 축소하거나 타국 영향을 새로 넓히지 않는다. 범위 변경은 별도 작업이다.

## 5. 후속 구현 시 작업 순서와 완료 기준

1. 원본·우리 코드 기준선과 버프 전항목 목록을 고정한다.
2. 정확한 게임 버전·DLC·언어 모드·플레이셋과 두 모드의 물리적 경로 및 로드 순서를 확인한다.
3. 핵심 세 파일에 최신 원본 변경과 우리 버프를 의미 단위로 병합한다.
4. 우리 전용 파일의 참조·ID·modifier와 제조사/MIO 연결을 확인한다.
5. `descriptor.mod`와 런처 `.mod`의 의존성·`replace_path`·경로를 검토한다. 구현 전 여러 원본 변형 의존성을 실제 구성과 대조한다. 최초 문서화 때는 설정을 변경하지 않았고, 이후 구현·새 플레이세트 테스트 허가 범위에서 필요한 변경을 수행했다. 실제 변경은 구현 기록을 따른다.
6. 최신 원본 기능 보존과 우리 버프 전항목 보존을 각각 확인한다. 새 게임 초기화·중복 지급 방지·중요 DLC 부정 경로와 저장/불러오기를 변경 위험에 맞춰 검증한다.
7. `[RESTORATION]` 등 원본 업데이트 대응과 기존 `[REBALANCE]`/`[NEW]` 버프 보존 내역을 구분해 기록한다. 원시값·동작 차이, 미검증 항목도 남긴다.

실행 검증 전에는 최신 원본이 실제 로드됐다거나 국뽕 버프 전부의 효과가 유지됐다고
완료 처리하지 않는다. 최초 문서화 시점에는 위 작업을 실행하지 않았다. 이후 코드 병합과
허가받은 테스트의 새 저장 재로드와 설정·기존 저장 복구는 구현 기록에 남겼다.
모든 버프의 실효 적용이나 변경 전 저장의 호환성을 완료 처리하지 않으며 엔진의 저장
이름 전환 실패와 완료한 종료·원복 절차를 구분한다. 원본 수정·커밋·푸시·Workshop 작업은 수행하지 않는다.
