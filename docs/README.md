## 현재 업데이트 반영 방향

원본 전체를 우리 폴더에 복사하지 않고 최신 원본과 국뽕팩을 함께 사용하는 구성을
확인한다. 우리가 덮어쓰지 않는 콘텐츠는 원본에서 사용하고, `common/characters/KOR.txt`,
`history/countries/KOR - Korea.txt`의 누락만 기존 파일에서 반영했다.
`common/ideas/korea.txt`는 이전 반영 원본 이후 변경이 없어 이번 재병합 근거가 없다.
나머지 국뽕 특성·시작 이벤트·혁신 포인트·건물·슬롯 상한·현지화는
기존 수치와 조건을 보존하며 참조와 실제 적용 경로를 확인한다.

11월 6일의 코드 병합과 3모드 새 게임·일부 버프 효과 관측은 구현 기록에 별도로 남겼다.
11월 14일 조합의 실행 검증 결과가 아니며 모든 버프 효과의 검증 완료를 뜻하지 않는다.
후속 구현에서는 두 파일 외의 의존성·`replace_path`·ID 연결도 확인한다.

## 별도 장기 설계: 신규 최강 프리셋

아래는 새 프리셋의 설계다. 현재 버프의 분해·새 ID 이동·상시 효과의 선택형 전환을
이번 업데이트 작업에 적용하지 않는다. GRT-211의 독립 시작 보너스도 기존 계약대로 보존한다.

기존 `gookppong` 시작 효과는 연구 슬롯과 일부 기초 기술·장비·부대를 주지만,
현재 HOI4의 모든 일반 기술, 교리, 네 종류 연구시설, 특수 프로젝트, 실제 첩보 작전
기간을 한꺼번에 해결하지 않는다. 따라서 최강 모드는 기존 효과에 수치를 더 얹는
형태가 아니라 다음 다섯 축을 분리해 설계해야 한다.

1. 대상 버전에 맞춘 일반 기술 허용 목록
2. 상호 배타성을 고려한 육·해·공 교리 완성
3. 육군·해군·공군·원자력 연구시설과 과학자 배치
4. DLC 조건을 고려한 특수 프로젝트 완료
5. 한국에만 적용되는 첩보 준비·침투·작전 기간 단축

최강 프리셋은 게임 규칙에서 명시적으로 선택하는 선택형 모드로 둔다. 원본에 이미 있는
`DEFAULT`, `GOOKPPONG_MIDDLE_POWER_ENABLED`, `GOOKPPONG_ENABLED` 흐름을
보존하고 새 최상위 단계를
추가하는 방식이 가장 추적하기 쉽다. 복원용 기본 동작과 기존의 중간 강도/구버전 국뽕
프리셋을 그대로 보존해야 호환성 복원과 의도적인 치트성 강화가 섞이지 않는다.

당시 문서화 후 구현을 요청받아 코드 병합을 진행했으며, 실제 실행 검증을 위한 사용자 설정
임시 전환과 새 플레이세트 테스트도 후속 허가를 받아 수행했다. 새 저장의 재로드·진행·
재저장과 설정·기존 저장 복구, Steam 플레이 표시 복귀까지 확인했다. 실제 검사 범위와
저장 이름 전환 실패 등 남은 제한은 구현 기록을 따른다.

전체 이관을 별도로 요청한 경우에만 `SOURCE_MIGRATION_PLAN.md`에 따라 독립 기준선을
구축한다. 새로운 최강 프리셋은 `GREATEST_MODE_DESIGN.md`를 사용하는 별도 개발 작업이다.
