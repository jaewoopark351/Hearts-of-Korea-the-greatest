# Hearts of Korea the Greatest 문서

이 폴더는 `C:\hoi\hearts_of_korea`를 읽기 전용 원본으로 삼아
`C:\hoi\Hearts of Korea the greatest`에 계승 모드를 만드는 작업을 설계한다.

현재 단계는 **문서화 전용**이다. 이 문서를 작성하면서 원본 코드 복사, 게임플레이
코드 수정, 디스크립터 변경, 게임 실행, Workshop 작업은 수행하지 않았다.

## 문서 목록

- [CURRENT_STATE_AUDIT.md](CURRENT_STATE_AUDIT.md): 현재 원본과 대상 프로젝트에서 확인한 사실, 누락된 강화 요소, 아직 확인하지 못한 항목
- [GREATEST_MODE_DESIGN.md](GREATEST_MODE_DESIGN.md): 한국 전용 `최강 국뽕` 프리셋의 기능 요구사항과 구현 방향
- [SOURCE_MIGRATION_PLAN.md](SOURCE_MIGRATION_PLAN.md): 원본을 덮어쓰지 않고 대상 프로젝트로 안전하게 이관하는 단계별 계획

## 한눈에 보는 결론

기존 `gookppong` 시작 효과는 연구 슬롯과 일부 기초 기술·장비·부대를 주지만,
현재 HOI4의 모든 일반 기술, 교리, 네 종류 연구시설, 특수 프로젝트, 실제 첩보 작전
기간을 한꺼번에 해결하지 않는다. 따라서 최강 모드는 기존 효과에 수치를 더 얹는
형태가 아니라 다음 다섯 축을 분리해 설계해야 한다.

1. 대상 버전에 맞춘 일반 기술 허용 목록
2. 상호 배타성을 고려한 육·해·공 교리 완성
3. 육군·해군·공군·원자력 연구시설과 과학자 배치
4. DLC 조건을 고려한 특수 프로젝트 완료
5. 한국에만 적용되는 첩보 준비·침투·작전 기간 단축

최강 프리셋은 게임 규칙에서 명시적으로 선택하는 선택형 모드로 둔다. 원본에 이미 있는
`DEFAULT`, `GOOKPPONG_MIDDLE_POWER_ENABLED`, `GOOKPPONG_ENABLED` 흐름을
보존하고 새 최상위 단계를
추가하는 방식이 가장 추적하기 쉽다. 복원용 기본 동작과 기존의 중간 강도/구버전 국뽕
프리셋을 그대로 보존해야 호환성 복원과 의도적인 치트성 강화가 섞이지 않는다.

## 작업 경계

- 원본 소스는 항상 읽기 전용이다.
- Steam Workshop 관리 폴더와 게임 설치 폴더는 수정하지 않는다.
- 첫 계승판은 새 Workshop 항목이어야 하며 기존 ID를 업로드 대상으로 사용하지 않는다.
- 일반 복원, 호환성 수정, 최강 프리셋은 커밋과 변경 기록에서 분리한다.
- 실제 구현 전 목표 HOI4 빌드, DLC, 플레이셋, 의존 모드, 로드 순서를 확정한다.

## 권장 작업 순서

`SOURCE_MIGRATION_PLAN.md`에 따라 원본을 이관하고 복원 기준선을 먼저 만든 뒤,
`GREATEST_MODE_DESIGN.md`의 최강 프리셋을 별도 작업으로 추가한다. 최강 기능부터
원본 파일에 직접 합치면 구버전 문제와 새 밸런스 문제를 구분하기 어려워진다.
